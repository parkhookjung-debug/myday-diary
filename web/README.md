# 마이데이 웹 디자인 공유

팀원이 맥과 윈도우에서 같은 디자인을 확인하고 수정할 수 있는 웹 앱입니다.

## 실행

Python 3를 설치한 뒤 저장소 루트에서 실행합니다.

- 맥: `./web/start-mac.command`
- 윈도우: `web\start-windows.bat`

브라우저가 열리지 않으면 http://127.0.0.1:8765 로 접속하세요. 종료할 때는 터미널에서 Ctrl+C를 누릅니다.

## 수정할 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 구조와 문구 |
| `desktop.css` | 색상, 글꼴, 배치, 반응형 디자인 |
| `app.js` | 날짜, 기록 블록, 자동 저장, 백업 기능 |
| `serve.py` | 컴퓨터 내부에서만 접속하는 정적 서버 |

수정 사항은 작업 브랜치에서 커밋하고 PR로 공유합니다. 디자인 파일 전체를 보내려면 `web/` 폴더를 압축하세요. 초기 시안은 `previews/myday-example.html`과 `previews/myday-example.png`에서 확인할 수 있습니다.

기록은 각 브라우저의 localStorage에 저장됩니다. 팀원끼리 기록이 자동 공유되지 않습니다. 개인 기록과 백업 JSON은 저장소에 올리지 마세요.
