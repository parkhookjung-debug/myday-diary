# 마이데이 macOS v0.3.10-preview

macOS 13 이상용 SwiftUI 앱입니다. Windows v0.3.9-preview의 기록 버전 1~4를 가져오고, Windows에서 읽을 수 있는 버전 4 JSON을 내보냅니다. Windows 원본의 일기 형식 100종과 자유 배치를 지원합니다.

## 실행과 빌드

`build/MyDay.app`을 더블 클릭하거나 응용 프로그램 폴더에 복사하세요. 이전 앱이 켜져 있으면 저장 후 종료하고 새 앱을 실행하세요. 빌드한 앱을 실행할 때는 개발 도구가 필요하지 않습니다.

소스에서 실행하려면 Command Line Tools(`xcode-select --install`)를 설치한 뒤 저장소 루트에서 `./macos/run.command`를 실행합니다. 앱과 ZIP만 만들려면 `./macos/build.command`를 실행하세요. 현재 맥의 CPU에 맞춰 Apple Silicon용 arm64 또는 Intel용 x86_64 앱을 만듭니다. 배포 ZIP의 CPU 표시를 확인하세요. 개발자 인증서 없는 로컬 서명을 사용하며 Apple 공증은 적용하지 않았습니다.

## Windows 기록 가져오기·내보내기

1. Windows 앱에서 **기록 백업**으로 JSON을 내보내 맥으로 옮깁니다. Windows의 `diary.json` 파일도 읽을 수 있습니다.
2. 맥 앱의 **기록 관리 → 맥·Windows 백업 가져오기…**에서 파일을 선택합니다.
3. 가져올 일수와 겹치는 날짜를 확인한 뒤 **가져오기**를 누릅니다.
4. Windows로 다시 옮길 때는 **기록 관리 → Windows 백업 내보내기…**로 만든 JSON을 Windows v0.3.9-preview 이상에서 가져옵니다.

Windows 기록은 기존 맥 기록과 합칩니다. **같은 날짜는 가져온 일기로 교체**하고 다른 날짜의 맥 기록은 유지합니다. 성장 날짜는 중복 없이 합칩니다. 장비 정보가 있는 백업은 장비를 적용하며, 장비가 없는 이전 백업은 현재 장비를 유지합니다. 가져오기 자체는 XP를 주지 않습니다.

다음 정보를 보존합니다.

- 글·사진·사진 설명·할 일·습관·감정, 블록 ID와 완료 상태
- 기분·배경·종이 스타일·자동/자유 배치, 제목·질문·너비 설정
- 블록의 논리 좌표와 크기
- 성장 날짜·장비, Windows 캐릭터 외형 ID, 저장된 **내 레이아웃** 데이터

Windows 캐릭터 외형 ID와 내 레이아웃은 맥 백업 및 Windows 재내보내기에 보존됩니다. Windows의 상몬 64종 외형 렌더링과 내 레이아웃 저장·관리 화면은 이번 범위에 포함되지 않았습니다. 맥 상몬은 기존 맥 전용 모습으로 표시합니다.

Windows 내보내기는 사진당 JPEG 2MB·긴 변 1,600픽셀, 사진 Base64 합계 64Mi 문자, 전체 JSON 128MB, 날짜당 200블록 제한을 확인합니다. 이전 맥 사진이 Windows 제한을 넘으면 파일을 내보내기 전에 오류를 알립니다. 맥 전용 기록의 빈 사진 블록은 Windows의 빈 사진 자리(`photo-slot`)로 내보냅니다.

## 일기 형식 100종

위쪽 **일기 형식**을 열어 분야를 고르거나 제목·질문·배치 이름을 검색하세요. 오른쪽에서 질문과 배치를 미리 보고 **이 형식 사용하기**를 누릅니다.

- 일상·회고·감사·마음·학습·계획·생활·관계·창작·추억의 10개 분야
- 긴 글·질문 카드·본문+메모·타임라인·편지·플래너·코넬 노트·나란히 비교 배치
- 빈 페이지에는 미리보기의 자유 배치와 종이를 적용합니다.
- 기존 일기에는 원래 글·사진·체크·좌표를 유지하고 빈 블록을 추가합니다. 자유 배치는 기존 블록 아래에 추가하고 자동 정렬은 순서대로 배치합니다. 종이는 선택한 형식의 스타일로 바뀝니다.
- 추가할 공간이나 200블록 제한을 넘으면 적용 전에 중단합니다. 형식만 추가해도 XP가 생기지는 않습니다.

제목·설명·질문은 Windows 릴리스 커밋 `9abf375745369fc9a45e0d5e918e0e8a8fb9c26b`의 원본 100종에서 추출했습니다. 목록은 앱에 포함되어 오프라인으로 동작합니다. 갱신 도구는 `tools/sync-windows-templates.py`이며 해당 커밋의 Git 객체가 있어야 실행할 수 있습니다.

## 자유 배치

1. 기록 아래의 **자유 배치**를 선택합니다. 현재 자동 배치 위치를 기준으로 시작하며 이미 저장한 자유 좌표는 유지합니다.
2. **배치 편집**을 누릅니다.
3. 블록의 **제목**을 끌어 이동하고, **오른쪽 아래 ↘**를 끌어 크기를 바꿉니다.
4. 마우스를 놓으면 저장합니다. **편집 완료**를 누르면 글을 다시 입력할 수 있습니다.

확대/축소는 보기만 바꾸며 저장 좌표에는 영향을 주지 않습니다. 넓은 페이지는 가로 스크롤로 볼 수 있습니다. 창 크기를 바꿔도 자유 좌표는 유지합니다. 위치는 0~10,000, 너비는 300~1,600, 높이는 180~1,400 논리 단위입니다.

**자동 정렬**은 창 너비에 맞춰 순서대로 보여 줍니다. **자동으로 다시 정렬…**은 확인 후 자유 좌표·크기를 다시 배치합니다. 글·사진은 유지합니다. 종이는 기본·줄 노트·도트 중 고를 수 있습니다.

## 기존 기능

- 날짜별 글·할 일·습관·감정 기록, 자동 저장, 순서 변경, 삭제 확인
- JPEG·PNG·HEIC·TIFF 사진 선택: 입력 40MB 이하, 긴 변 1,600픽셀 이하 JPEG로 보관
- 전체 본문·사진 설명 검색, Command+F
- 배경 3종과 날짜별 응원 캐릭터 선택
- 상몬 애니메이션, 바탕화면 드래그 이동, 메뉴 막대에서 보기·숨기기
- 기록 활동을 저장한 실제 날짜에 하루 10 XP, 5일마다 레벨 상승, 색 8종 순차 해금
- 마법 무기와 보주 각각 6속성, 독립 장착·해제

빈 블록·템플릿·배치·테마·장비 변경, 단순 재실행 및 백업 가져오기는 XP를 주지 않습니다. 글 입력·사진 추가·사진 설명·할 일 또는 습관 완료가 성장 활동입니다. 과거 일기를 수정해도 XP는 실제 작성한 오늘 기준입니다. 쉬는 날에도 성장은 유지됩니다.

## 맥 기록과 백업

기록 위치는 `~/Library/Application Support/MyDay/`입니다. 날짜별 JSON, `companion.json`, Windows에서 가져온 정보를 담는 `windows-metadata.json`을 로컬로 저장합니다. 사진은 JSON에 포함되고 서버에 전송하지 않습니다. 이전 기본 SwiftUI 맥 앱의 기록과 버전 1 맥 백업도 읽습니다.

**맥 백업 내보내기…**는 모든 기록과 Windows 호환 정보를 포함하는 `myday-macos` 버전 2 JSON을 만듭니다. **맥 백업 가져오기**는 기존 맥 기록 전체를 교체하며, Windows 백업은 위에서 설명한 병합 방식으로 처리합니다. 확인 창에서 방식을 안내합니다.

가져오기 직전 기록은 Application Support의 `MyDay-previous-…` 폴더에도 남깁니다. 잘못된 백업은 적용 전에 거부하며 저장 실패 시 편집 내용을 유지하고 날짜 이동을 중단합니다. Android·web 백업 호환, 자동 동기화 및 AI 답변은 제공하지 않습니다.

## 검증

`build/MyDay.app/Contents/MacOS/MyDay --self-test`는 개인 기록을 쓰지 않고 임시 폴더에서 다음을 검사합니다.

- 기존 맥 기록·백업 호환, 저장·재읽기, 하루 XP 제한, 장비, 저장 실패 시 날짜 이동 방지
- Windows 버전 1~4, .NET 날짜 목록과 객체형 날짜 목록, 사진과 모든 블록 종류
- Windows → 맥 편집 → Windows 변환의 글·사진·체크·제목·질문·좌표·성장·장비·레이아웃 보존
- 중복 날짜·블록 ID, 잘못된 사진·좌표·미지원 버전 거부, 잘못된 복원 후 기존 파일 유지
- 원본 100종 전부의 적용·독립성·기존 기록 보존·Windows 내보내기, 검색, 배치 한계

`--render-preview`는 임시 예시 기록으로 기본·좁은 화면·템플릿·자유 배치 PNG를 저장소 루트 기준 `macos/build/`에 만듭니다. macOS 그래픽 세션에서 실행하세요.

`.github/workflows/macos.yml`은 맥 빌드·검증 후 원본 Windows 커밋을 체크아웃해 실제 Windows `DiaryStore.Read`와 `DataContractJsonSerializer`로 맥 내보내기를 검사하도록 구성되어 있습니다. 이 CI는 로컬에서 실행한 검증과 별개이며 GitHub에 반영한 뒤 실행 결과를 확인해야 합니다. 이 맥에서 실제 Windows 실행과 Intel 실행은 확인하지 않았습니다.
