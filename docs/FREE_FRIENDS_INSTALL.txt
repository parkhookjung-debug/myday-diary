마이데이 친구 0.14.0 — 무료 친구 초대 버전

설치 파일: MyDay-Friends-0.14.0-free.apk
Android 8 이상에서 사용할 수 있습니다.

1. 본인과 친구가 모두 같은 APK를 설치하세요.
2. '마이데이 친구' 앱에서 친구 일기를 열고 카카오로 로그인하세요.
3. 친구 초대에서 코드를 만들어 카톡으로 보내세요.
4. 상대가 앱에서 코드 입력을 하면 친구 요청이 도착합니다.
5. 초대한 사람이 친구 관리 → 새로고침 → 수락을 누르세요.
6. 공개할 글·사진을 직접 선택하고 미리보기를 확인한 뒤 공개하세요.
   선택하지 않은 개인 기록은 친구에게 보내지 않습니다.

사진은 한 번에 최대 10장 추가하고, 제목·장소·설명을 쓸 수 있습니다.
친구 공개에는 사진을 최대 6장 선택할 수 있습니다.
초대코드는 24시간 동안 한 번 사용할 수 있고, 새 코드를 만들면 이전 코드는 취소됩니다.

기존 앱과 이름·설치 ID가 다른 별도 앱입니다. 기존 앱을 삭제하지 마세요.
기존 일기는 기존 앱의 설정·백업에서 JSON 백업을 내보낸 뒤 새 앱에 가져오세요.
사진이 포함된 백업인지 확인하고, 새 앱에서 기록을 확인한 후 원본을 보관하세요.

Supabase 서울 지역 Free 프로젝트에 서버를 연결했습니다.
결제수단·유료 요금제·유료 Render 서비스는 설정하지 않았습니다.
무료 저장 공간·전송량 한도가 있고, 비활성 프로젝트는 일시 정지될 수 있습니다.
공개 사본은 다시 공개해야 수정 내용이 반영됩니다.

확인한 항목: Android 빌드·단위 검사·Lint, DB 접근 정책, 배포 서버 응답과 위조 인증 차단.
아직 확인하지 못한 항목: 실제 휴대폰 두 대에서 카카오 로그인 → 초대 수락 → 사진 공유.
로그인 오류가 나면 앱 화면의 오류 문구와 발생 시점을 알려 주세요. 비밀번호는 보내지 마세요.

전체 소스와 서버 재설정 방법은 소스 ZIP의 docs/FREE_FRIENDS_SETUP.md에 있습니다.
서버 관리자 키·DB 비밀번호·서버 비밀값은 APK와 소스 ZIP에서 제외했습니다.
