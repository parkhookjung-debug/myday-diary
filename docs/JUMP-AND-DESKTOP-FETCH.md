# 통통 점프와 바탕화면 공놀이 · Windows

2026-11-13. 플레이룸에 통통 점프를 추가하여 게임 4종을 고를 수 있습니다. 공놀이는 별도 점수 게임이 아닌 바탕화면 상몬과 노는 기능입니다. 기존 간식·슬링샷·낚시·최고점수·결과 카드·일기·성장·로컬 채팅은 유지합니다. Windows 개발 버전이며 현재 공개된 기본 0.15.0 Release의 첨부 파일을 교체하지 않습니다.

## 통통 점프

- 플레이룸에서 **통통 점프 → 놀러 가기**를 누릅니다. **Space / ↑ / W / 클릭**으로 시작하고 점프합니다.
- 장애물은 뛰어넘고 공중의 간식을 먹습니다. 피해 없이 넘긴 장애물 +20점, 간식 +10점입니다. 부딪힌 장애물은 나중에 지나가도 점수를 주지 않습니다.
- 60초·목숨 3개. 부딪히면 목숨 -1과 짧은 보호 시간이 있습니다. 간식을 놓쳐도 목숨을 잃지 않습니다. 시간이 지나면 낙하가 아닌 횡방향 이동 속도를 조금씩 높입니다.
- 공중에서는 다시 뛰지 못하며 키를 계속 눌러도 착지 후 자동으로 뛰지 않습니다. 점프할 때 길어지고 착지할 때 잠깐 납작해집니다.
- **P / Esc / 일시정지**, **R / 처음부터**를 사용합니다. 다른 창을 활성화하면 자동으로 멈추고 **P / 계속하기**로 재개합니다. Space는 점프 전용입니다.
- 완료한 판의 최고점수·완료 횟수는 기존 게임과 같은 별도 `Games/scores.json` 파일의 `jump` 항목에 저장합니다. 결과 카드도 PNG로 보관합니다. 진행 중인 판을 닫으면 완료 기록으로 반영하지 않습니다.

## 바탕화면 공놀이

1. 플레이룸 아래 **바탕화면 공놀이**, 또는 상몬 우클릭 메뉴의 **공놀이 시작 / 공 다시 꺼내기**를 누릅니다. 플레이룸은 작업 표시줄로 내려갑니다.
2. 상몬 옆에 작은 주황색 공이 나타납니다. 공을 잡고 움직이다 놓으면 던진 방향과 속도에 따라 튕깁니다. 천천히 놓아도 중력에 따라 떨어집니다.
3. 상몬이 공을 따라가 잡고, 입 앞에 들고 시작했던 자리로 돌아온 뒤 잠깐 기뻐합니다. 다시 공을 던져 계속 놀 수 있습니다. 공을 잡고 있는 동안에는 상몬이 기다립니다.
4. **상몬 또는 공 우클릭 → 공놀이 끝내기**로 마칩니다. 상몬을 직접 클릭/드래그하거나 숨겨도 공놀이가 끝납니다. 평소 클릭으로 일기 열기와 드래그·던지기는 그대로 사용합니다.

공놀이는 상몬이 있는 모니터의 작업 표시줄을 제외한 작업 영역에서 진행합니다. 상몬을 다른 화면으로 직접 옮기면 공놀이가 끝나므로 다시 시작합니다. 화면 크기가 변하면 공과 귀환 위치를 새 작업 영역 안으로 조정합니다. 메뉴를 열면 공과 추적을 잠시 멈춥니다. 자유 이동을 꺼도 직접 시작한 공놀이는 진행하며, 끝난 뒤에는 기존 자유 이동 설정을 따릅니다.

공은 64×64 픽셀의 별도 투명 창이고 상몬의 기존 타이머에서 물리를 계산합니다. 화면 전체를 덮는 입력 창을 만들지 않으며, 공과 상몬을 직접 누른 영역에서만 조작합니다. 공의 표시·최상위 옵션은 상몬과 함께 관리하고 상몬 숨기기·종료 시 공 창도 정리합니다.

## 실행 파일

- `SangmonGame.exe`: 네 게임과 공놀이 버튼이 있는 플레이룸.
- `SangmonFetch.exe` 또는 `MyDay.exe --desktop-fetch`: 플레이룸을 작업 표시줄에 두고 바탕화면 공놀이부터 시작합니다. 작업 표시줄에서 플레이룸을 다시 열 수 있으며 플레이룸을 닫으면 이 모드에서 만든 상몬·공도 종료합니다.
- `MyDay.exe`: 일기 앱. **상몬 게임 · 플레이룸**과 상몬 우클릭에서 실행합니다. 게임 단독 실행은 일기 저장소를 읽지 않습니다. 단독 공놀이 상몬을 클릭하면 플레이룸으로 돌아갑니다.

공놀이는 점수·경험치·출석을 지급하거나 기록 파일을 만들지 않습니다. 점프 점수도 일기 경험치와 분리합니다. 서버·외부 패키지·게임 엔진을 추가하지 않습니다.

## 검증

`windows/build.ps1 -OutputDirectory build/jump-fetch-validation`로 빌드합니다. `MyDay.exe --self-test`는 점프 궤적·이중 점프 방지·장애물/간식 판정·점수 중복·보호 시간·30/120FPS·60초 종료·새 점수 저장과 공 던지기·전체 추적/귀환·모서리 접근·캡처 취소·음수 좌표·화면 변화·종료를 검사합니다. 기존 일기·상몬·세 게임 검사도 함께 실행합니다.

`--jump-fetch-preview <폴더>`는 개인 기록 없이 네 게임 선택 화면·작은 창·점프·공 투명도·실제 포인터 경로·실제 상몬 이동의 전체 가져오기·직접 상몬 조작·숨기기 정리를 검사합니다. 공놀이 미리보기는 재현 가능한 테스트 장면이며 실제 바탕화면 녹화는 아닙니다. 전체 `--smoke-test`에도 포함합니다.
