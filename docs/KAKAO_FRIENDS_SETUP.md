# 친구 일기 연결 안내

현재 버전은 **0.14.0 무료 초대코드 방식**입니다.

[무료 서버·카카오 로그인·친구 초대 설정 안내](FREE_FRIENDS_SETUP.md)를 확인하세요.

이전 카카오 친구 목록 API·유료 Render 서버 방식은 사용하지 않습니다. 앱 안에서 카톡으로 코드를 보내고, 상대가 요청한 뒤 초대한 사람이 수락해야 공개 일기가 열립니다.

기존 앱의 기록을 옮길 때는 기존 앱에서 JSON 백업을 내보낸 다음 **마이데이 친구 → 설정·백업 → 백업 복원**에서 가져옵니다. 원래 앱을 먼저 삭제할 필요가 없습니다. 이 PC에서 만든 0.13 친구 미리보기 앱을 설치했다면 같은 서명과 앱 ID의 0.14로 업데이트할 수 있습니다.
