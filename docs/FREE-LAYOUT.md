# Windows 일기 자유 배치

Windows에서 글·할 일·습관·감정 블록의 위치와 크기를 직접 정합니다. 자동 정렬 형식도 함께 사용할 수 있습니다.

## 사용하기

1. 일기 창 위쪽 **배치 편집**을 누릅니다. 자동 정렬 상태였다면 자유 배치로 전환합니다.
2. 블록의 **제목 영역**을 잡아 원하는 위치로 드래그합니다.
3. 오른쪽 아래 **↘**를 잡아 너비와 높이를 조절합니다.
4. **편집 완료**를 누르고 내용을 입력합니다. 편집 중에는 글 입력을 잠시 잠급니다.

위치와 크기는 현재 날짜에 자동 저장됩니다. 날짜를 이동하거나 앱을 다시 실행해도 유지합니다. 겹친 블록은 최근 이동한 블록이 위에 표시됩니다. **자동 정리**는 현재 블록을 겹치지 않는 카드 배치로 다시 정리합니다. 이 작업은 내용과 체크 상태를 유지합니다.

배치 선택에서 **자동 정렬**로 바꿨다가 **자유 배치**로 돌아오면 마지막 자유 위치를 복원합니다. 작은 창에서는 블록 크기를 강제로 바꾸지 않고 가로·세로 스크롤로 이동합니다. 드래그 중 Esc 또는 마우스 캡처 취소는 해당 이동을 되돌립니다.

## 팀에서 수정하는 위치

| 파일 | 역할 |
| --- | --- |
| `windows/Core/DiaryData.cs` | 날짜별 LayoutMode, 블록 X/Y/Width/Height와 저장 검증 |
| `windows/Core/DiaryLayout.cs` | 자동 정렬·처음 자유 배치·새 블록 위치·이동과 크기 제한 |
| `windows/UI/DiaryBoard.cs` | 스크롤 가능한 캔버스와 드래그 이벤트 연결 |
| `windows/UI/BlockCard.cs` | 제목 핸들·↘ 핸들·편집 중 글 입력 잠금 |
| `windows/UI/DiaryWindow.cs` | 배치 선택·편집·자동 정리·날짜 이동 |

좌표와 크기는 Windows DPI에 독립적인 논리 단위로 저장합니다. JSON Version 1에 선택 필드를 더했으며 이전 기록은 자동 정렬 형식으로 읽습니다. 기존 글·ID·체크·기분·테마·캐릭터는 유지합니다. 자유 배치는 현재 Windows에 적용했으며 Android 화면의 배치는 별도입니다.

자동 테스트는 기존 JSON 읽기, 내용·ID·체크 보존, 형식 전환, 새 블록 위치, 최소 크기·좌표 범위, 날짜별 저장·재로드, 잘못된 위치를 저장할 때 기존 파일 보존을 확인합니다. 네이티브 검증은 제목 드래그·↘ 리사이즈·취소·스크롤 후 이동·날짜와 디스크 재로드·작은 창·삭제 버튼을 확인합니다.
