# 상몬 플레이룸 · Windows 3종 게임

**추가 업데이트:** [통통 점프와 바탕화면 공놀이](JUMP-AND-DESKTOP-FETCH.md)를 추가하여 현재 플레이룸은 네 게임입니다. 아래는 기존 세 게임의 상세 안내입니다.

2026-11-13 · 간식 산책을 확장하고 슬링샷과 낚시를 추가했습니다. Windows에서 먼저 구현합니다. 현재 공개된 기본 0.15.0 Release와 구분되는 개발 버전이며 Mac·Android의 게임 화면은 아직 포함하지 않습니다.

## 실행

일기 앱 왼쪽 **상몬 게임 · 플레이룸**, 또는 바탕화면 상몬의 같은 우클릭 메뉴에서 엽니다. 게임만 사용하려면 `SangmonGame.exe`를 실행합니다. 같은 바이너리인 `MyDay.exe --game-hub`도 플레이룸을 열며, `MyDay.exe --snack-game`은 간식 산책을 바로 엽니다. 단독 실행은 일기 저장소를 읽지 않습니다.

게임을 선택하고 **게임 시작 / Space**를 누릅니다. 창을 닫으면 플레이룸으로 돌아갑니다. 다른 프로그램을 활성화하거나 최소화하면 진행 중인 게임은 자동으로 일시정지됩니다. 다시 활성화해도 자동으로 재개하지 않습니다. **계속하기** 버튼으로 돌아옵니다. 공통으로 **P(슬링샷·낚시) / Esc**는 일시정지, **R**은 새 판입니다. 일시정지 중에는 시간·물리·입질 판정이 멈춥니다.

## 1. 간식 산책 / 오늘의 도전

- 마우스 좌우·방향키·A D로 이동하고 사과·딸기·쿠키를 먹습니다. 기본 +10점, **연속 5개마다 +10점 보너스**입니다. 간식을 놓치거나 피해를 받으면 현재 콤보가 끊기고 그 판의 최고 콤보는 남습니다.
- 돌·가시에 닿으면 목숨 -1, 1.2초 동안 연속 피해를 막습니다. 목숨 3개와 60초 제한을 유지합니다. Space로 정지/계속합니다.
- 플레이룸의 **오늘의 같은 배치 도전**은 시작한 날짜에 고정된 순서를 사용합니다. 재도전·다른 조작·30/120FPS에서도 같은 시점에 같은 간식이 나옵니다. 게임 창을 연 날짜를 화면에 표시하고 그 창의 재도전에는 같은 날짜를 유지합니다.
- 일반 최고점수와 날짜별 도전 최고점수는 따로 저장합니다. 도전 기록은 최근 날짜 순 최대 31개를 보관합니다. 온라인 순위표 없이 결과 카드로 점수를 공유할 수 있습니다.
- 도전 배치 알고리즘·규칙을 변경할 때는 도전 버전(`v1`)과 기록 ID도 함께 갱신해야 합니다.

## 2. 상몬 슬링샷

- 상몬의 몸을 잡고 **뒤로 당겼다가 놓으면 반대 방향으로 발사**됩니다. 당기는 동안 점선으로 첫 충돌 전의 예상 경로를 봅니다. 아래쪽으로 당기면 위로 날아갑니다.
- 최대 당김·발사 힘에 제한이 있고 화면 테두리와 바닥에서 튕깁니다. 충돌하거나 잠깐 날아간 뒤 발사대로 돌아옵니다.
- 60초, 10번의 기회 안에 5개의 고리를 통과합니다. 통과 +100점, 중심 통과 +150점입니다. 5개를 모두 통과하거나 기회·시간을 모두 쓰면 종료합니다.
- 잡은 채 포커스를 잃거나 정지하면 발사를 취소합니다. 취소는 발사 횟수를 쓰지 않습니다. 비행 중 정지하면 재개 시 같은 위치에서 계속 날아갑니다. Space 또는 P로 정지/계속합니다.

## 3. 느긋한 낚시

- **Space / 물가 클릭**으로 낚싯줄을 던집니다. 찌를 보며 기다립니다.
- **입질!** 표시가 나오면 한 번 눌러 게이지를 엽니다. 움직이는 표시가 초록 칸 안에 올 때 한 번 더 누릅니다.
- 성공 +30점, 초록 칸 중심에 맞추면 +50점입니다. 물고기 이름·잡은 수·완벽 성공 수를 보여줍니다. 너무 빨리 누르거나 놓쳐도 다시 던질 수 있습니다.
- 한 판은 60초입니다. 낚시에서는 Space가 동작 버튼이고 **P / Esc / 일시정지**로 멈춥니다. 키를 길게 눌러도 한 번의 동작으로 처리합니다.

## 기록과 결과 카드

완료한 판을 게임별로 기록합니다. 최고점수·마지막 점수·완료 횟수를 `%LOCALAPPDATA%/MyDay/Windows/Games/scores.json`에 저장합니다. 낮은 점수가 기존 최고점수를 덮어쓰지 않습니다. 파일 잠금 후 최신 기록을 다시 읽고 임시 파일과 원자 교체를 사용합니다. 읽을 수 없거나 미래 버전인 파일은 보존하고 저장 문제를 게임 화면에 표시합니다.

진행 중인 판을 닫으면 완료 기록으로 저장하지 않습니다. 게임 점수는 일기 경험치·출석·성장에 지급하지 않습니다. 기존 일기·사진·백업 버전 1~9는 유지합니다. 게임 기록은 공통 일기 백업과 별도로 보관합니다.

완료 화면의 **결과 카드 저장**을 누르면 사용자가 고른 위치에 PNG를 저장합니다. 게임 이름·점수·콤보/통과/낚시 결과·도전 날짜와 상몬 그림을 그려 만듭니다. 바탕화면이나 개인 일기를 캡처하지 않으며 자동 업로드하지 않습니다.

## 검증

`windows/build.ps1 -OutputDirectory build/playroom-validation` 후 `MyDay.exe --self-test`, `--smoke-test <출력 폴더>`를 실행합니다. `--mini-games-preview <출력 폴더>`는 개인 기록 대신 메모리 자료로 실제 플레이룸과 세 게임·완료 화면·결과 카드를 출력합니다. `sync-snack-game.py --check`, `sync-mini-games.py --check`는 공통 원본과 생성 코드의 일치를 검사합니다.

검사는 콤보·같은 배치·프레임 간격, 5개 고리의 실제 도달 가능한 궤적·발사 취소·제한·득점 중복, 입질·무적이 아닌 정지 시간·게이지 성공/실패, 최고점수 재읽기·동시 저장·실패 시 파일 보존·미래 버전 보존·일기 파일 불변을 확인합니다. 실제 화면 검사는 키 해제·키 반복·포인터 경로·캡처 취소·판 완료 기록 1회·카드 렌더링을 확인합니다.
