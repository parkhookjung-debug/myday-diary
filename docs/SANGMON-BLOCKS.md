# 상몬 블록 쌓기 · Windows 개발 버전

2026-11-14. 상몬 실루엣으로 만든 네 칸 블록을 쌓는 테트리스 방식의 게임입니다. 파스텔색 상몬 네 마리가 I·J·L·O·S·T·Z 모양으로 내려옵니다. 기존 캐릭터 렌더러의 기본 상몬을 작은 투명 스프라이트로 한 번 그려 재사용하며 별도 이미지 다운로드·게임 엔진은 사용하지 않습니다.

플레이룸에는 **간식 산책·슬링샷·낚시·통통 점프·불꽃 요리·상몬 블록 쌓기** 여섯 게임이 있습니다. **바탕화면 공놀이**는 플레이룸 아래 버튼으로 계속 이용합니다. `codex/windows-app` 작업 브랜치의 Windows 개발 기능이며 현재 공개 `v0.15.0-preview` Release와 구분됩니다. Mac·Android의 게임 화면은 아직 구현하지 않았습니다.

## 실행

- 일기 앱의 **상몬 플레이룸 → 상몬 블록 쌓기 → 놀러 가기**를 누릅니다.
- 게임 단독 실행은 `SangmonGame.exe` 또는 `MyDay.exe --game-hub`입니다. 블록 게임을 바로 열려면 `MyDay.exe --blocks-game`을 사용합니다.
- **게임 시작 / Space / Enter**로 시작합니다. 시작할 때 누른 Space를 계속 눌러도 첫 블록이 자동으로 떨어지지 않습니다. 놓았다가 다시 눌러 조작하세요.

## 조작

| 입력 | 동작 |
| --- | --- |
| ← / → | 좌우 이동. 꾹 누르면 짧게 기다린 후 일정한 간격으로 반복 |
| ↑ / X | 시계 방향 회전 |
| Z | 반시계 방향 회전 |
| ↓ | 빠르게 한 칸씩 내리기. 꾹 누르면 반복 |
| Space | 옅은 착지 위치까지 바로 내리고 고정. 새로 누를 때 한 번만 실행 |
| 화면 왼쪽 이동·회전 버튼 | 마우스로 한 번씩 조작 |
| 화면의 바로 내리기 / 아래 바로 내리기 | 마우스로 착지 위치까지 바로 내리기 |
| P / Esc / 일시정지 | 멈추기. P / 계속하기로 재개 |
| R / 처음부터 | 이번 판을 초기화하고 재시작 |

다른 창으로 이동하면 자동 일시정지합니다. 돌아온 뒤 계속하기를 누르고 키를 새로 눌러 움직입니다. 정지 시간에는 중력·착지 고정 시간·점수가 진행되지 않습니다.

## 규칙과 점수

- 판은 **가로 10칸 × 세로 20칸**입니다. 일곱 모양을 한 번씩 섞는 묶음으로 생성하여 특정 모양이 계속 나오지 않는 일을 줄이고, 다음 블록 세 개를 표시합니다.
- 가로 한 줄을 빈칸 없이 채우면 그 줄이 사라지고 위 블록이 아래로 내려옵니다. 여러 줄을 동시에 지울 수 있습니다.
- 옅은 상몬은 현재 블록의 **착지 위치 미리보기**이며 실제로 쌓인 블록이 아닙니다.
- 바닥에 닿은 뒤 약 0.4초 동안 위치를 조절할 수 있습니다. 성공한 이동·회전으로 고정 시간을 다시 얻는 횟수는 블록당 15번으로 제한합니다. 벽·바닥 가까이에서 회전할 때는 몇 칸의 보정 위치를 검사하며, 다른 블록을 뚫고 돌지 않습니다.
- **시간 제한은 없습니다.** 새 블록이 들어올 자리가 막히거나 블록을 화면 위에 걸친 채 고정해야 하면 종료합니다.

| 동작 | 점수 |
| --- | --- |
| 한 줄 지우기 | 100 × 현재 속도 레벨 |
| 두 줄 동시에 | 300 × 현재 속도 레벨 |
| 세 줄 동시에 | 500 × 현재 속도 레벨 |
| 네 줄 동시에 | 800 × 현재 속도 레벨 |
| ↓로 실제 한 칸 내리기 | +1 |
| Space로 내린 거리 | 한 칸마다 +2 |

다섯 줄마다 속도 레벨이 한 단계 올라가고 최대 Lv.20입니다. 해당 줄을 지우기 전 레벨로 점수를 계산합니다. 낙하 간격은 처음 0.85초에서 점점 짧아지되 최소 0.12초입니다. 최고점수 파일 범위에 맞춰 점수는 1,000,000점에서 멈춥니다. 이 레벨은 **블록 게임의 속도**이고 일기 캐릭터의 레벨과 별개입니다.

## 기록과 기존 기능

종료한 판만 `%LOCALAPPDATA%/MyDay/Windows/Games/scores.json`의 `blocks` 항목에 최고점수·최근점수·완료 횟수를 저장합니다. 중간에 창을 닫은 판은 저장하지 않으며 진행 중인 판의 이어하기는 제공하지 않습니다. 종료 후 **결과 카드 저장**으로 날짜·점수·지운 줄·속도 레벨·블록 수를 PNG에 담습니다.

기존 다섯 게임 점수는 함께 보존합니다. 파일 잠금·재읽기·원자 교체와 손상 파일 보존 처리는 기존 방식을 사용합니다. 새 점수 ID를 모르는 예전 실행 파일은 이 점수 파일을 읽지 못할 수 있으므로 최신 개발 실행 파일을 사용하세요. 게임 점수로 일기 경험치·출석·재화를 지급하지 않습니다. 일기·사진·성장·백업·로컬 채팅이나 기본 바탕화면 상몬 외형은 변경하지 않습니다. 게임 블록의 색은 코디/변신 기능을 다시 추가하는 것이 아닙니다.

## 검증

`./windows/build.ps1 -OutputDirectory build/blocks-validation`로 빌드하고 `MyDay.exe --self-test`로 검사합니다. 일곱 모양·7개 묶음·벽/바닥 회전·실패한 회전 보존·고스트 위치·낙하 점수·단일/동시/비연속 줄 삭제·레벨·착지 지연·반복 지연 제한·꼭대기 종료·30/120FPS·1,500회 혼합 입력·기존 점수 보존을 포함합니다.

`MyDay.exe --blocks-preview <폴더>`는 개인 기록 없이 실제 WinForms 창을 열어 여섯 게임의 전체/작은 창, 키 내려감/올라감·자체 이동 반복·회전·단일 즉시 낙하·창 비활성화·마우스 낙하·네 줄 삭제·기록 한 번 저장·PNG를 검사합니다. 상몬 블록의 투명 배경도 확인합니다. 전체 `--smoke-test`에도 포함합니다.

[실제 폼·상몬 블록과 검사 장면](../previews/blocks-20261114/README.md). 게임 장면은 재현 가능한 테스트 배치이며 개인 바탕화면·일기를 캡처하지 않습니다.
