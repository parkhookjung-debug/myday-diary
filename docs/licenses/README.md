# QR 라이브러리

- Windows `DeviceQr.cs`: Project Nayuki QR Code generator를 v6-L 범위로 포팅했습니다. Copyright © Project Nayuki, MIT. [원본 라이선스](../../windows/Core/DeviceQr.LICENSE.txt).
- Android: ZXing core 3.5.3, Copyright ZXing authors, Apache License 2.0. [라이선스 전문](ZXing-APACHE-2.0.txt), [공식 소스·버전](https://github.com/zxing/zxing/tree/zxing-3.5.3). 라이브러리를 수정하지 않고 Gradle 의존성으로 사용합니다.
- Mac: OS의 Core Image를 사용합니다.

앱 실행 파일 묶음에도 이 문서와 두 라이선스를 포함합니다. 이전 선택형 Python 도구의 QR 라이선스는 `tools/vendor/README.md`에 있습니다.
