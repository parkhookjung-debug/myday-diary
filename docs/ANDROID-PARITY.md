# Windows·Android 기능 통일

현재 Windows와 Android 0.6.0 소스는 같은 상몬·아이템·일기 형식·백업 규칙을 사용합니다. UI와 시스템 연동은 각 플랫폼의 입력 방식에 맞춰 구현합니다.

| 기능 | Windows | Android |
| --- | --- | --- |
| 글·할 일·습관·감정·사진 | 블록 카드 | 블록 카드·시스템 사진 선택기 |
| 일기 형식 | 100종·8가지 배치 | 같은 100종·같은 좌표와 질문 |
| 자유 배치·크기 | 마우스 드래그 | 길게 잡기·↘ 크기 조절·확대·화면 이동 |
| 내 레이아웃 | 최대 50개·관리·재사용 | 같은 규칙·빈 칸으로 재사용 |
| 달력·전체 본문 검색 | 별도 창 | 달력 탭·사진 설명 포함 |
| 상몬 | 56종 + 보상 8종 | 같은 ID·그림·해금 레벨 |
| 성장 | 출석·일기 등 6미션·하루 최대 40 XP·50 XP/레벨 | 같은 규칙·성공한 저장에서만 지급 |
| 장비 | 50형태×6재질·장비 300종·8슬롯 | 같은 이름·설명·그림·8슬롯 |
| 백업 | 버전 1~6 읽기·수집 내역은 버전 6 쓰기 | 같은 형식·사진·배치·성장·장비 보존 |
| 홈 캐릭터 | 투명 바탕화면 창·클릭으로 앱 열기 | 라이브 배경화면·별도 홈 위젯에서 앱 열기 |
| 촉각 반응 | 마우스 조작 | 체크·잡기·놓기·장착·상몬 터치에 짧은 햅틱 |

Android의 라이브 배경화면은 다른 앱 위에 떠 있는 오버레이가 아닙니다. 홈 화면에서 움직이며 적용은 시스템 미리보기에서 확정합니다. Windows의 알림 영역·다중 모니터 창 제어는 Android 메뉴로 복제하지 않습니다. 자동 클라우드 동기화는 없으며 백업 파일을 옮깁니다.

## 햅틱 기준

| 동작 | 반응 |
| --- | --- |
| 탭·날짜·캐릭터 선택 | 짧은 선택 피드백 |
| 체크·사진 추가 | 확인 피드백 |
| 블록을 길게 잡기 | 길게 누르기 피드백 |
| 놓기·크기 조절 완료·순서 이동 | 짧은 놓기 피드백 |
| 검·보주 장착/해제 | 확인 피드백 |
| 사용 불가·입력 실패 | 거절 피드백 |

입력하는 모든 글자나 드래그의 모든 프레임마다 진동하지 않습니다. 앱 설정과 휴대폰 터치 피드백 설정을 따르며 지원 기종·OS에 맞는 시스템 상수로 호출합니다. 배경화면에는 View가 없으므로 API 29 이상에서 시스템 설정을 확인하고 미리 정의된 단발 진동을 사용합니다. 설정을 강제로 우회하지 않습니다. API 26~28의 배경화면 터치 진동은 생략합니다.

## 공동 작업과 데이터

그림·64종 ID·해금 레벨·아이템·100종 질문은 Windows 코드가 원본입니다. Windows에서 고친 뒤 `./tools/export-android-assets.ps1`를 실행하면 Android의 `assets/catalog.json`, `assets/sangmon`, `assets/portraits`, `assets/items`, `SangmonIdentity.kt`, 상호 호환성 검사 자료가 갱신됩니다. 목록은 작은 정지 썸네일을, 상몬 미리보기와 배경화면은 동작 프레임을 사용합니다. 생성 자산을 직접 수정하면 다음 생성 때 덮어써집니다.

Android 좌표는 Windows와 같은 논리 단위입니다. 저장 백업은 Windows의 대문자 필드와 Key/Value 날짜 배열을 사용하며 Android 햅틱 설정은 추가 필드입니다. Windows는 추가 필드를 무시합니다. 가져오기는 같은 날짜를 백업 내용으로 교체하고 성장 날짜를 중복 없이 합칩니다. 장비 없는 이전 백업은 현재 장비를 유지합니다. 가져오기 전 확인 창을 제공합니다.

AtomicFile로 기존 저장본을 지키고, 큰 파일 저장은 직렬 백그라운드 작업으로 처리합니다. 실패한 일기는 화면에 유지하며 다시 저장 전 날짜 이동을 막습니다. 위젯·배경화면은 본문/사진 없는 설정 캐시를 읽습니다. 기존 Android SharedPreferences는 안전한 이전 뒤에도 삭제하지 않습니다.

## 다음에 하기 좋은 작업

1. 실제 갤럭시에서 진동 세기·블록 손가락 크기·런처 동작을 확인합니다.
2. 팀이 Android/Windows의 같은 시나리오를 사용해 회전·종료·재실행·백업 이동을 함께 검증합니다.
3. 배포 서명 설정을 승인·완료해 이후 APK를 기록 삭제 없이 덮어 설치합니다.
4. 접근성 글자 확대·TalkBack·태블릿/가로 화면을 보완합니다.

동기화·AI보다 기록 보존과 일상 사용 흐름 검증을 먼저 권장합니다.

성장은 10·20·30·50 XP 구간으로 세분화했으며 [선물 상자·수집 도감](SANGMON-COLLECTION.md)을 함께 제공합니다. 새 뽑기·교환 내역은 버전 6 JSON을 사용하고 이전 버전 1~5도 읽습니다.
