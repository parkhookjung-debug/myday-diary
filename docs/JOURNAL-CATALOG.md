# 일기 형식 20개 목록

반복해서 쓰기 좋은 대표 용도를 10개 분야에서 2개씩 골랐습니다. 앱 사용 통계가 없으므로 실측 인기 순위가 아니라, 매일 기록하기 쉬운 범용성과 분야 균형을 기준으로 정리한 목록입니다.

**일기 형식 · 블록 추가**에서 분야를 고르거나 제목·질문·배치 이름을 검색합니다. 블록은 같은 목록의 **기본** 분류에서 추가하며, Mac은 글·할 일·습관·감정·사진·영상을 제공합니다. 기본 블록이나 레이아웃 목록의 ☆를 누르면 **즐겨찾기** 분류에 함께 모입니다.

## 다시 만들기

목록은 앱과 같은 `shared/catalog/templates.json`에서 생성합니다. 형식 원본을 수정한 뒤 `python tools/sync-desktop.py`를 실행해 Windows와 Mac 생성 파일을 갱신하고, Android 카탈로그도 같은 20개 ID로 맞춥니다.
