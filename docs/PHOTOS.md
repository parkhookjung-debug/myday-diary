# Windows 일기 사진

일기 아래 **＋ 사진**을 누르고 JPG/JPEG, PNG, BMP 또는 GIF 파일을 선택합니다. 사진 블록 아래에 설명을 입력하면 사진과 함께 자동 저장됩니다. 여러 사진은 각각 블록으로 추가합니다.

**배치 편집**에서 사진 블록의 제목을 잡아 이동하고 오른쪽 아래 ↘로 크기를 바꿉니다. 사진 전체가 보이도록 비율을 유지합니다. **편집 완료**를 누르면 설명 입력과 **사진 바꾸기**를 사용할 수 있습니다. 사진을 교체해도 설명과 배치는 유지합니다. 블록의 ×는 확인 후 사진과 설명을 함께 삭제합니다.

사진은 해당 날짜의 기록에 들어갑니다. 원본 경로를 참조하지 않으므로 원본을 옮겨도 기록이 유지되고, 왼쪽 **기록 백업**의 JSON에는 사진도 포함됩니다. 다른 PC에서 **가져오기**를 누르면 사진과 설명·배치를 함께 복원합니다. 기존 사진 없는 백업도 읽습니다.

## 저장 형식

- 입력 사진은 최대 20MB, 2,500만 화소이며 가로·세로 각각 최대 12,000픽셀입니다.
- 휴대폰 사진의 EXIF 회전을 반영한 뒤 긴 변 최대 1,600픽셀, 품질 85의 JPEG로 저장합니다. 작은 이미지는 확대하지 않습니다. 투명 영역은 흰색으로 처리하고 GIF는 첫 프레임을 저장합니다.
- 원본의 위치·촬영 정보 등 메타데이터를 제거합니다. 원본 파일은 수정하지 않습니다.
- 변환된 사진 한 장은 최대 2MB입니다. 전체 기록의 사진 Base64 데이터는 64MiB, 실제 JPEG 합계로 약 48MiB까지 저장합니다. 전체 기록·백업 파일은 128MiB 이하입니다.
- `diary.json`과 JSON 백업의 선택 필드 `DiaryBlock.Photo`에 Base64 JPEG를 담습니다. 설명은 `Text`, 위치·크기는 기존 좌표 필드에 저장합니다.
- 입력·교체는 파일 해석과 용량 검증을 모두 마친 뒤 반영합니다. 손상된 사진을 포함한 백업은 적용 전에 거부하고 기존 기록 파일을 유지합니다.
- 화면용 미리보기는 필요한 시점에 생성하고 긴 변 최대 800픽셀로 제한합니다. 블록 제거·날짜 이동 시 이미지 자원을 해제합니다. 저장 사진은 최대 1,600픽셀을 유지합니다.

## 수정할 파일

| 영역 | 파일 |
| --- | --- |
| 입력·회전·압축·사진 검증 | `windows/Core/DiaryPhoto.cs` |
| 모델·전체 용량·저장·백업 검증 | `windows/Core/DiaryData.cs` |
| 사진 선택·교체·날짜별 연결 | `windows/UI/DiaryWindow.cs` |
| 사진 블록·설명·교체 버튼 | `windows/UI/BlockCard.cs` |
| 비율을 유지하는 사진 미리보기 | `windows/UI/PhotoView.cs` |
| 사진 보존·손상·용량·회전 테스트 | `windows/PhotoTests.cs` |

사진 첨부는 현재 Windows에 적용했습니다.
