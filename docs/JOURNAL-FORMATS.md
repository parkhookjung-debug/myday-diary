# 일기장 형식

Windows 일기 위쪽 **일기 형식**을 누르면 6종의 미리보기가 열립니다. 형식을 고르고 **이 형식 추가**를 누른 뒤 작성합니다. 배경 선택 옆에서 **노트·카드·도트** 표면을 따로 바꿀 수도 있습니다.

| 형식 | 구성 |
| --- | --- |
| 자유 일기 | 넓은 글 한 칸에 오늘의 이야기 |
| 하루 회고 | 기억에 남는 장면, 오늘 알게 된 것, 내일의 작은 약속 |
| 감사 일기 | 고마웠던 순간, 전하고 싶은 말 |
| 질문 일기 | 오늘을 한 단어로, 내 마음이 머문 곳, 나에게 해주고 싶은 말 |
| 불렛 저널 | 오늘의 우선순위, 나를 위한 루틴, 짧은 메모 |
| 상몬에게 편지 | 상몬에게 이야기하듯 쓰는 감정 기록 |

기존 글·체크·자유 배치는 보존하고 새로운 블록을 추가합니다. 저장하지 않은 새 날짜의 기본 빈 글 칸만 첫 형식 선택 시 교체합니다. 자유 배치에서는 추가된 블록이 기존 블록 아래에 나타나며 제목 드래그·↘ 크기 조절로 꾸밀 수 있습니다. 블록 한도 200개를 넘으면 일부만 추가하지 않고 전체 추가를 취소합니다.

안내 질문은 빈 입력칸의 도움말로 표시됩니다. 글을 쓰기 시작하면 사라지며 답변란에 질문이 자동 입력되지 않습니다. 형식의 제목·질문과 종이 스타일은 날짜별로 저장하고 JSON 백업에 포함합니다. 형식 선택은 원래 기분·배경·상몬 선택을 바꾸지 않습니다.

새 날짜는 넓은 글 일기 한 칸으로 시작합니다. 이전 저장본에는 템플릿 필드가 없어도 기존 글·블록·체크·배치를 그대로 읽습니다. 상몬에게 편지는 로컬 감정 기록이며 AI 답변은 제공하지 않습니다.

팀 수정: `windows/Core/DiaryTemplates.cs`에서 형식의 이름·설명·제목·질문·블록 종류를 바꾸고, `windows/UI/TemplateGallery.cs`에서 선택 화면을 바꿉니다. 모델 선택 필드는 `PageStyle`, `DiaryBlock.Title`, `DiaryBlock.Prompt`이며 저장 검증은 `windows/Core/DiaryData.cs`에 있습니다.

참고한 방식은 [Day One의 질문형·감사·회고 템플릿](https://dayoneapp.com/features/journal-templates/)과 [Notion의 일기 구성 사례](https://www.notion.com/templates/daily-journal)입니다. 한국어 질문은 이 프로젝트에서 새로 작성했습니다.
